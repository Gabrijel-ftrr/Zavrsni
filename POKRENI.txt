Open PowerShell in this folder
(in File Explorer, click the address bar and type: powershell)

Set Java 17:

$env="C:\Program Files\Java\jdk-17"

Build the executable JAR file:

& "C:\Program Files\Apache\apache-maven-3.9.11\bin\mvn.cmd" clean package -DskipTests

Run:

java -jar target\stock-predictor-1.0.0.jar

(if that file does not exist, check the filename in the target folder -
it may be stock-predictor-1.0.0-shaded.jar)

IMPORTANT: do not use "mvn javafx" - this method puts
the libraries on the module path, which breaks Weka
(NoClassDefFoundError: weka.core.Capabilities).
